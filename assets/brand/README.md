# The three pictures this page asks for

`/spark-event` is the design file the event team handed over, unchanged, with its three images
pointing here instead of being pasted into the middle of the page. The page looks after the orb
itself (that one lives in `assets/logo/orb-160.png` already).

Drop in these three files with these exact names and the page is finished. Nothing else needs
editing, because the HTML already asks for them at these addresses.

| file                  | what it is                                             | how to get it                                                           |
| --------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------- |
| `sharjah-next.png`    | the Sharjah Next logo, top left of the page             | open the design file in a browser, right click the logo, Save image as   |
| `spark.png`           | the SPARK logo, top right of the page                   | same, on the SPARK mark                                                  |
| `hero.jpg`            | the photograph behind the dark panel at the top        | same, right click the picture                                            |

Transparent PNG is right for the two logos: the header behind them is the sand colour, and the
page draws them 34px tall (27px on a narrow phone), so send the ones the design used rather than a
small screenshot. The photograph can be anything from 1200px wide up; the page covers it, so a
crop of it is fine.

Until the three files exist the page still works, it just shows the alt text in the header and the
night colour behind the hero instead of the photograph. The form, the pass and Mira are unaffected.
